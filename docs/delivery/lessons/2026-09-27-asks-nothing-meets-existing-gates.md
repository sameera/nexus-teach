# Lesson: an "asks nothing" promise must be checked against the gates it passes through

Epic #111 was sized S and shipped as one pull request of about 200 lines, so the estimate held.

The gap was in the planning. A success metric said the agent path asks the learner nothing. That path runs through two existing steps that need a person's answer. The first approval of a plan needs the suite and grading commands, and inferring them is forbidden. The re-plan needs the input the roadmap was first built from, and the plan does not record it. The build honoured those older rules and added a question each time. Analysis flagged one of them as low, and both were deferred as follow-up epics at close.

Next time an epic promises that a path asks nothing, list every gate and verb that path runs through while planning. For each one that needs human input, either say in the epic how the input is supplied, or narrow the promise.
