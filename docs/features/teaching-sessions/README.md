# Teaching Sessions

One sitting with a learner: what the session verifies before it teaches, the lesson it writes on
arrival, the concept it drills first, and where it pauses.

## Epics

- **One session teaches one lesson, written on arrival** — [#4](https://github.com/sameera/nexus-teach/issues/4) (filed in Nexus as #407)
- **A stub is planned when the learner reaches it** — [#67](https://github.com/sameera/nexus-teach/issues/67)
- **The decision record is written before the lesson needs it** — [#68](https://github.com/sameera/nexus-teach/issues/68)

## Notes

The opening cold drill shipped here, under #4. What a *second* drill earns — a reference page the
learner returns to — was planned as [#34](https://github.com/sameera/nexus-teach/issues/34) and
files under [Workbook Rendering](../workbook-rendering/README.md), because a reference page is a
rendered page even though a drill is what earns it.

Grading is not built yet. It is an open stub, *The learner's work is graded, and the result is
remembered*, [#5](https://github.com/sameera/nexus-teach/issues/5).
